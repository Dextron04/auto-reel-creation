Privacy Policy

Effective date: September 15, 2026

YouTube Shorts Automation by Dextron is a private tool operated by Dextron to create and upload videos to the operator's YouTube channel.

Google and YouTube data

With the operator's permission, the tool uses the YouTube Data API and the youtube.upload permission to upload videos and manage the videos created by this automation. It does not read or sell unrelated Google account data.

How data is used

OAuth credentials are used only to authenticate the operator's YouTube channel and perform requested uploads. Video titles, descriptions, and files are used to create the requested YouTube videos.

Storage and sharing

OAuth credentials and generated media are stored on the operator's private server. Access tokens are used transiently for API requests. Google data is not sold, rented, or shared with third parties except as necessary for Google's YouTube API to complete an upload requested by the operator.

Retention and deletion

Generated media and related records are retained only for operating and troubleshooting the automation. The operator may delete generated media or revoke the tool's Google access at any time through the Google Account security settings.

Security

Credentials are kept in private server configuration and are not included in public pages or video metadata. No security method is perfect, so access is limited to the operator and the systems required to run the automation.

Changes and contact

This policy may be updated when the automation's data practices change. For privacy questions, contact Dextron at privacy@dextron04.in.
